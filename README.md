# GRAIR

Cinematic luxury jewelry experience built with Next.js 16.3.3, React Three Fiber, and an original diamond scene.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Click **Click to Grair**, then scroll, swipe, or use the arrow keys.

The interface follows the GRAIR chapter structure. The gem, ring, necklace, score, and panther mark are original — the studio’s model, textures, and music are not included.
